Quick answer

A test plan lists each requirement, how it will be tested, the pass criterion and when; the product's characteristics decide which tests apply.

Every product needs functional, user, fit, cosmetic, packaging and production-consistency checks. Power, radio, outdoor use, moving parts, children and food contact each add their own tests, several of which usually need a test laboratory.

How to use the plan

  1. Copy the plan and add a measurable pass criterion to every line before testing.
  2. Ask a test laboratory to confirm the standards and tests for your category, and quote for formal testing.
  3. Run pre-compliance and design-verification tests on engineering prototypes, before tooling is final.
  4. Record results and evidence; they become part of the technical file.

How to read your result

The number of laboratory tests is a rough guide to certification effort and cost: products with mains power, radios or batteries, or intended for children, usually need the most. References are examples of where requirements commonly come from, not a complete list; regulations and designated standards depend on the exact product. FAQ

What should a product test plan include?

For each requirement: what is tested, the method or standard, the number of samples, a pass criterion set in advance, when it will be tested, and the result with evidence. The plan should cover function, users, durability, safety, compliance, packaging and production consistency.

Does this tool tell me which standards my product must meet?

No. It gives examples of where requirements commonly come from. The applicable regulations and designated standards depend on the exact product; confirm them with a test laboratory or the official GOV.UK guidance.

When should testing start?

Functional and user testing start with the first prototypes. Pre-compliance testing for electrical, EMC and radio products should happen on engineering prototypes, and formal testing on production-intent units before or alongside tooling.

How many samples do I need for testing?

It depends on the test: some standards specify sample numbers, and durability tests often need several units. Ask your laboratory early, because samples can be a significant cost before production tooling exists.

Why is the copied plan different from the table?

The copied version is grouped by development stage and adds blanks for pass criteria and results, so you can paste it into your own document and complete it.
